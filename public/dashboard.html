📈 Sistema de Niveles y XP

Configura la cantidad de experiencia que los usuarios ganan por enviar mensajes y las alertas de nivel.

El bot enviará un mensaje Embed al canal cuando un usuario suba de nivel.

Por cada mensaje, el bot otorgará una cantidad de XP aleatoria entre el mínimo y máximo establecido. Hay un tiempo de espera de 1 minuto entre mensajes para evitar abusos.
