# Contribuir / Contributing

¡Gracias por tu interés! / Thanks for your interest!

1. Abre un issue para comentar el cambio antes de hacer una PR grande. / Open an issue before a big PR.
2. Haz un fork, crea una rama y envía una pull request pequeña y centrada. / Fork, branch and send a small PR.
3. Describe qué cambia y cómo lo has probado. / Describe what changed and how you tested it.
